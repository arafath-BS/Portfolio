# Arafath Hossen Santo — Portfolio

A creative, non-conventional portfolio website showcasing my projects, skills, and background as a Computer Science & Engineering student at AIUB.

## ✨ Features

- **Interactive particle background** with mouse-reactive constellation effects
- **Typing animation** hero section
- **Scroll-triggered reveal animations** for all content sections
- **Orbital skill visualization** on desktop
- **Animated stat counters**
- **Responsive design** — works on mobile, tablet, and desktop
- **Dark space theme** with accent glow effects

## 🛠 Tech Stack

Pure HTML, CSS, and JavaScript — no frameworks, no build step.

## 🚀 Deployment

This site is designed to be deployed via **GitHub Pages**:

1. Go to **Settings → Pages** in this repository
2. Under **Source**, select **Deploy from a branch**
3. Choose `main` branch, `/ (root)` folder
4. Click **Save**

The site will be live at `https://<username>.github.io/Portfolio/`

## 📁 Structure

```
├── index.html   — Main HTML page
├── style.css    — All styles (dark theme, animations, responsive)
├── script.js    — Particles, typing effect, scroll reveals, orbit
└── README.md    — This file
```
